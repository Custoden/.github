# Contributing

Thanks for helping improve Custoden.

* **Bugs and corrections:** open an issue in the relevant repository with steps to reproduce.
* **Missed detections or false positives:** open an issue on [Custoden/docs](https://github.com/Custoden/docs/issues) with the package or workflow. If it should not be public, use [private vulnerability reporting](SECURITY.md) instead.
* **Pull requests:** keep them focused on one change and describe why it is needed. Run the repository's checks before submitting.

Security issues must never be reported in public issues. See [SECURITY.md](SECURITY.md).
